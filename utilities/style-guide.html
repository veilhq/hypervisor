Sticky Note (.scratch-card)

Fully-filled note cards for the ephemeral scratch pinboard. The surface is the full-strength cycle color, so all inner content switches to --note-ink (the app background) for contrast. The peeled top-right corner reads as paper lifting off the board and grows on hover. Color cycle is c1 / c2 / c3 (accent, warm, cool) — --comp is deliberately excluded, reserved for alerts and indicators.

∷ 2m ago
Accent note (c1). Short entries square up to a minimum height; long ones grow taller.
∷ 1h ago (*)
Cool note (c3), with the out-of-order marker shown.
∷ yesterday
Warm note (c2). Hover a card to reveal its actions and grow the corner peel.

Skill Row (.hv-skill-row)

A bordered list of skills as collapsible rows. Each row is a native <details>: the .hv-skill-rowhead summary shows the icon, name, trigger phrase, and a chevron; the .hv-skill-rowbody reveals the description, a meta line, and the section outline on click. No JS needed.
